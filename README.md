CI/CD Pipeline for Java Application

Objective:

Developed a basic CI/CD pipeline to automate the build, testing and deployment of a Java application using GitHub, Jenkins, and Docker.

Tools & Technologies used:

1.GitHub

2.Jenkins

3.Docker

4.Java

5.Eclipse IDE

Project Workflow:

~Developed a basic Java application.

~Stored source code using GitHub.

~Configured Jenkins to automate the build and testing process.

~Created a Docker image for the application.

~Ran the application inside a Docker container.

Learning Outcomes:

~Understood the CI/CD workflow and automation process.

~Gained hands-on experience with GitHub, Jenkins, and Docker.

~Learned the basics of contanerization and automated deployment.


Project Architecture:

Developer -> GitHub -> Jenkins -> Build & Test -> Docker image -> Docker Container -> Application Output
